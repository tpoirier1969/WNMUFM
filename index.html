What the reports are good for

Core long-term series

These deserve Day / Week / Month history because NPR's unique audience counts cannot always be reconstructed from daily rows.

  • Streaming listeners, sessions, listener-hours and session duration
  • Website active users, pageviews and engagement
  • Audio downloads, users and downloads per user
  • NPR One localized listeners and average minutes

High-value drilldowns

  • Audio program → dated downloads/users → player → episode
  • Website traffic channel trends and DMA/country geography
  • Streaming device share
  • NPR One hour-of-day, station audio type, podcast and client/platform

Mostly duplicate or derived

  • “Vs previous” scalar cards once historical periods are stored
  • Website traffic-channel share file when the richer channel table is present
  • Aggregate audio player totals when player trend covers the same range
  • Derived ratios such as views/user and sessions/listener are useful checks, not independent audience counts

Still missing

  • Live-stream hour/sub-hour detail needed to cross-reference individual scheduled programs
  • Website page/landing-page/referrer detail needed to explain what content drives visits
  • Device-specific website history unless separately filtered exports are collected
  • Audience Leads inventory, if it provides cross-product listener context
